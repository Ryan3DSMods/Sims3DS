## Adaptations made by this project (also CC BY-SA 4.0)

Generated by `tools/banner3d/make_scene.py` and `tools/banner3d/flat_banner.py` from `thesimslogo_red_backer.stl`:

| File | What was changed |
|---|---|
| `src/platform/3ds/banner3d/banner_scene.gltf` + `banner_scene.bin` | recoloured (white letter faces, red sides/back, thin red outlines built into the geometry), mesh refined along the outline, centred and rescaled for the HOME Menu camera, a ±25° sway animation added, converted to glTF 2.0 (and at build time to CGFX) |
| `src/platform/3ds/banner3d/banner_scene_static.gltf` | the same without the animation |
| `src/platform/3ds/banner3d/banner_palette.png` | the 16×16 red/white palette texture the scene samples |
| `src/platform/3ds/banner.png`, `src/platform/3ds/icon.png` | the static scene rendered to the flat 256×128 HOME banner and the 48×48 icon |
